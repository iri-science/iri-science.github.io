Experiment with shared interfaces

Repeatable exercises help researchers and infrastructure providers test discovery, job submission, monitoring, and file access across independently operated systems. Use the public hackathon exercises and the implementation guide to explore interoperability in an environment you are authorized to use.

The developer entry points connect these exercises with reference implementations, adapters, and client tooling.

The FIRST concept

The proposed Federated IRI Science Testbed (FIRST) describes a progressive design, experiment, test, and refine cycle for exploring IRI design patterns and integration gaps.

The Federated IRI Science Testbed (FIRST) is further described in its 2023 white paper: https://doi.org/10.2172/2205149

Historical testbed plans: FY2024–2025

The planning material identified these activities for FY2024–2025:

  • Catalog existing testbeds at the ASCR compute facilities, e.g., ALCF Edith, NERSC PerlmutterOnDemand, OLCF ACE testbed, ESnet testbed
  • Co-design and implement plan to connect existing ASCR testbeds together using ESnet testbed network.
  • Develop a best current practice connection service template that can be used to connect other (e.g. non-ASCR) test environments to the IRI testbed.
  • Publish facility-specific testbed access procedures, acceptable use policies, etc.
  • Identify and execute early test cases to validate initial IRI testbed design, e.g., GRETA/Deleria, EJFAT, and LCLStream.
