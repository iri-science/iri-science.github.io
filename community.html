Bring your scientific and infrastructure experience

Researchers, infrastructure providers, and software developers help shape IRI by sharing requirements and testing how shared interfaces work in practice. Describe a workflow, contribute an adapter or example, report an interoperability problem, or propose a change to the specification.

IRI combines technical interfaces with engagement, trust, policy, and governance. Participation connects those perspectives while providers retain their own operational and authorization decisions.

Find a technical subcommittee

  • Outreach and Engagement connects scientific use cases, requirements, and community participation.
  • Interfaces develops cross-facility interface requirements, specifications, and implementation guidance.
  • TRUSTID develops trust and cybersecurity design patterns for cross-facility workflows.

Contribute to the specification

Start with the Contributing guide and RFC Process. Use the specification repository for proposed changes to shared contracts, profiles, and vocabulary.

The DOE IRI development organization hosts reusable software and examples. Repository contributions complement the wider IRI governance structure.

Share an implementation or a practical result

Help maintain the implementation directory, contribute a repeatable example, or share experience for IRI in Practice. Website updates can be proposed in the website repository.
