Choose your starting point

Build workflows across independently operated infrastructure, connect a provider, or contribute to the shared contract.

  • Published technical guidance

    Architecture explanations, discovery patterns, and implementation guidance.

  • Primary development organization

    Reusable software and examples developed in the DOE IRI GitHub organization.

  • Active specification source

    Versioned specifications, RFCs, registries, profiles, and OpenAPI sources.

Build a scientific workflow

Begin with Getting Started and the workflow notebooks. The public hackathon exercises provide a repeatable discovery, submission, monitoring, and output-retrieval sequence.

Follow each provider's documentation for credentials, allocations, and supported operations. Use the deployed service description to understand the version and capabilities available to your workflow.

Connect infrastructure

Read the Implementation Guide, map your resources to shared types and profiles, and connect provider-specific business logic through an adapter. The Hypermedia and Discovery guide explains how to advertise relationships and operations.

Use the Testbed page for experimentation context and meet the implementation community for collaboration.

Develop the shared contract

The IRI 2.0 overview introduces the current development model. Follow the RFC Process and Contributing guide to turn implementation experience into proposed changes.

Software and examples

  • Python reference implementation

    The FastAPI framework delegates provider-specific behavior to facility adapters. Configure the API groups your provider implements.

  • Java reference implementation

    A Spring Boot implementation documenting read-only facility metadata, resources, incidents, events, sites, and locations. Consult its README for current endpoint coverage.

  • Demo adapter starter

    Per-domain example adapters with demonstration data provide a starting point for replacing behavior with provider integrations.

  • Client and orchestration toolkit

    Python client tooling for compute workflows, with notebook examples and Airflow integration material in the repository.

  • Workflow notebooks and exercises

    Examples of authentication, filesystem operations, compute submission, and output collection, including the public hackathon suite.
